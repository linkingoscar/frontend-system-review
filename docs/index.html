Frontend System Review

证据驱动的前端系统评审 Skill —— 面向仓库、架构、PR 与运行中 Web 界面的系统级评审，覆盖业务匹配、技术栈、模块边界、类型契约、状态数据流、渲染性能、UI/UX、无障碍、测试、CI/CD、安全与可观测性。

证据驱动 系统级评审 可重复审计

📋

评审模式

模式 适用对象 输出
仓库系统评审 完整项目、目录或技术栈 架构与工程质量报告
变更评审 PR、diff、提交或若干文件 仅报告变更新增或放大的问题
运行时体验评审 URL、本地页面、截图或可启动应用 响应式、交互、a11y、性能与视觉问题
方案评审 RFC、架构图、选型说明 决策风险、替代方案和验证计划

核心纪律

  1. 先检查现有材料，再提问
  2. 将事实、推断和未知分开，不编造文件、行号、命令结果或指标
  3. 每条问题都给出证据、影响、具体修复与验证方法
  4. 严重度与置信度分离，证据不足的高影响事项标为"待验证"
  5. 先报告会改变结论的问题，再报告打磨项
  6. 只在用户要求时修改代码
  7. 匹配业务与团队约束，不默认推荐微前端、Monorepo 或重写

评分与结论

证据状态

  • 已确认
  • 高可能
  • 待验证
  • 不适用

严重度

  • P0 阻断上线
  • P1 重要
  • P2 改进

评分

12 个维度 0–5 分，默认权重合计 100；总分与等级 A（85+）B（70+）C（55+）D；证据覆盖率 <70% 标"暂定"

上线结论

  • 阻断上线
  • 修复后可上线
  • 可上线但需跟进
  • 可接受
  • 无法判断

任何已确认 P0 优先于总分

跨平台安装

兼容 Agent Skills 开放标准（agentskills.io），支持 Codex、Claude Code、OpenCode、Gemini CLI、Cline、Cursor、Copilot、Windsurf、Zed 等主流平台。1 个总控与 6 个专项的规范源均位于 skills/；安装指南见 INSTALLATION.md。

平台 安装方式
通用（推荐） 复制到 ~/.agents/skills/frontend-system-review/（Codex、Gemini、Cursor、Copilot、Zed、Windsurf、OpenCode 原生读取）
Codex 复制到 ~/.agents/skills/ 或 ~/.codex/skills/，会话内 /skills 查看
Claude Code 复制到 ~/.claude/skills/ 或 .claude/skills/，会话内 /skills 查看
OpenCode 复制到 ~/.config/opencode/skills/ 或 .opencode/skills/
Gemini CLI gemini skills install linkingoscar/frontend-system-review
Cline 复制到 ~/.cline/skills/（需在设置中启用 Skills 实验功能）
一键脚本 ./install.sh（Windows: install.ps1）默认安装通用目录；传 --platform all 可铺开全部平台

2

3
