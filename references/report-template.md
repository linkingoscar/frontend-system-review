# 前端系统评审报告模板

按实际范围删去不适用章节。先写结论和 findings，再写优点与路线图。

## 目录

1. 正式报告模板
2. 紧凑格式
3. 无 findings 格式

## 2. 紧凑格式

对单个文件、PR 或快速扫描，使用：

```markdown
## Findings

### [P1][高置信度] F-001 — 标题
- 位置：`path:line`
- 证据：
- 影响：
- 修复：
- 验证：

## 结论
- 修复后可合并。
- 未覆盖：运行时性能、真实认证状态。
```

## 3. 无 findings 格式

没有 findings 时使用：

```markdown
未发现可报告问题。

剩余风险：本次未覆盖……；已执行……；未执行……。
```
